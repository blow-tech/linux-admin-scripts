## Migration and remaining limits

Checkers now return 3 for UNKNOWN, 2 for usage and 0 for successful help. Alert on every nonzero result. Date-named log rotations require explicit `-f`; automatic inclusion is limited to `.N`/`.N.gz`. Backup `--verify-archive` cannot pass unsupported formats. The README describes changed backup, service, configuration and audit interfaces retained from September.

Application-consistent backup restoration, real Nginx apply/reload/rollback, actual mount/capacity behavior and platform integration still require disposable lab validation before deployment. Backup verification reads metadata and archives in separate operations; run against completed, stable backups. File archive/checksum publication is not a single transaction; incomplete artifacts remain available for investigation. Log scan timeout limits are per input, not a storage or total-job budget.
